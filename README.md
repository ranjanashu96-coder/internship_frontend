# RKNexora Frontend

Next.js 14 App Router frontend for Admin, College, Mentor and Student roles.

## Setup
```bash
cp .env.example .env.local
npm install
npm run dev
```

Backend base URL is configured with `NEXT_PUBLIC_API_URL`.

## Student registration entry point

Open `/register`, or use the visible **Registration number se account activate karein** link on `/login`.
The student must already exist in the backend `students` table through Admin/College manual creation or Excel upload.
